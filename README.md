# Luqueee's Homebrew tap

Install [rexpresence](https://github.com/Luqueee/rexpresence) on macOS:

```sh
brew install luqueee/tap/rexpresence
```

Run `rexpresence` to start sharing. Use `brew upgrade rexpresence` to update or `brew uninstall rexpresence` to remove the formula. Installing it does not start a watcher or edit your Rex configuration. The optional Rex palette module is at `$(brew --prefix rexpresence)/share/rexpresence/rexpresence.lua`.
