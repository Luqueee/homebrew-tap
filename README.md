# Luqueee's Homebrew tap

Install [rexpresence](https://github.com/Luqueee/rexpresence) on macOS:

```sh
brew install luqueee/tap/rexpresence
```

Run `rexpresence setup` to add the Discord actions to Rex's command palette. It shows the changes and asks before writing. Run `rexpresence` separately to start sharing. Use `brew upgrade rexpresence` to update or `brew uninstall rexpresence` to remove the formula.
